### SQL

- Основные запросы: фильтрации, агрегации, джоины, оконные функции
- Уметь доставать данные из разных таблиц
- Решать типовые задачи: количество активных пользователей, объединение таблиц данных

### Python

- Основные библиотеки для аналитики: `numpy`, `pandas`, `scipy`, `matplotlib`
- Задачи для Python: более сложные расчёты, статистика, расчёт AB-тестов, доверительные интервалы, корреляция, регрессия
- Автоматизация: обработка и трансформация данных, генерация и отправка отчетов

### Визуализация данных

- Типы визуализаций: временные ряды, воронки, фильтры по метрикам
- Задачи: поиски трендов, аномалий, презентация данных бизнесу
- BI-системы от самой простой к самой сложной с точки зрения входа, настройки и гибкости для конечного пользователя:

1. **Metabase**  
    Очень простой интерфейс, легкая установка, дружелюбен к новичкам, понятен даже без сильного технического бэкграунда.    
2. **Amplitude**  
    Ориентирован на продуктовую аналитику, простота работы для анализа пользовательских метрик, минимальные требования к SQL, но сфокусирован только на своем сегменте.    
3. **Power BI**  
    Дружелюбен для начинающих, быстрое подключение к разным источникам данных, визуальный drag&drop, но при желании позволяет глубокую кастомизацию.
4. **Tableau**  
    Очень развитый визуальный слой, сравнительно просто освоить базовые операции, но есть множество продвинутых функций и собственных языков для создания формул.    
5. **Apache Superset**  
    Open source, требует ручной установки и первоначальной настройки. Прост в базовых задачах, но при расширении — высокая гибкость и сложность за счет кастомизации, интеграций и зависимостей.    
6. **Looker**  
    Основан на собственном языке LookML для сложного моделирования данных, требует времени на изучение, отлично подходит для больших команд и продвинутого data governance.    
7. **HEX**  
    Больше ориентирован на data scientists и аналитиков, совмещает SQL, Python, визуализацию и коллаборацию. Может использоваться как "BI++", подразумевает продвинутую работу с кодом и кастомными сценариями.
### Excel

- Стартовые навыки: сводные таблицы (Pivot), простая атрибуция данных
### Статистика

- Основы: центральная предельная теорема, базовые знания по теории вероятностей
- AB-тестирование: понимание принципов, расчет доверительных интервалов, p-value
- Практические кейсы: задачи для принятия бизнес-решений на основе статистики

### Системы управления базами данных (СУБД) и хранилища

- Знать принципы работы: ClickHouse, Snowflake, Google Cloud, Data Lake
- ETL процессы: понимать extract, transform, load (только базово на старте)
- Инструменты для построения моделей данных
- DAG: https://airflow.apache.org/docs/apache-airflow/stable/core-concepts/dags.html
- DBT: https://www.getdbt.com/

- Уметь работать с большими массивами данных
- Старт с бесплатных курсов/ресурсов: например, Stepik по статистике и Python
